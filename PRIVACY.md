# Privacy Policy

This fork of Material Files is an open source app provided at no cost and intended for use as is.

## Information Collection and Use

This app does not collect, upload, sell, or share personal information for analytics or advertising.

This fork removes Google Analytics for Firebase and Firebase Crashlytics. It also removes Shizuku/Sui integration and uses the root/libsu backend for privileged file operations.

Files and settings selected or created by the user remain on the user's device unless the user explicitly uses a network feature such as FTP, SFTP, SMB, WebDAV, or another remote storage provider.

## Log Data

This app does not include a third-party crash reporting or analytics SDK. If the app crashes, Android may keep local system logs on the device according to the operating system behavior, but this fork does not automatically upload those logs to the developer.

## Network Access

The app may access the network only when the user uses features that require network access, such as remote file servers or network storage.

## Security

No method of electronic storage or transmission is 100% secure. Use care when granting root access or connecting to remote storage providers.

## Changes to This Privacy Policy

This policy may be updated when app behavior changes.
